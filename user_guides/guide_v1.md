 # DeepBoardGO Basic Controls Guide

  This short guide covers the main mouse controls and a few useful settings
  for playing and reviewing games in DeepBoardGO.

  ## Camera Controls

  - **Hold Left Mouse Button + Drag**: Change the viewing angle around the
  board.
  - **Hold Right Mouse Button + Drag**: Move the camera position across the
  board.
  - **Mouse Wheel**: Zoom in or out.

  These controls let you quickly switch between a close study view, a full-
  board view, and a more cinematic 3D angle.

  ## AI Analysis Controls

  When **AI Analysis** is enabled, suggested moves appear directly on the
  board.

  - **Hover over a suggested stone** to preview its PV/follow-up sequence.
  - **Hold the left mouse button on a suggested stone** to request more PV
  moves.
  - Keep holding until the progress indicator completes.

  This is useful when you want to look deeper into one AI recommendation
  without changing the current board position.

  ## Advanced Board Settings

  Open **Advanced Board Settings** to customize the board appearance and
  viewing experience.

  You can adjust options such as:

  - Board base color
  - Grid color
  - Wood type and board texture
  - Bowl appearance
  - Stone set, thickness, and spacing
  - Board margin and thickness
  - Camera presets: Top, Angle, and Low
  - Lighting, background, and visual effects

  Use these settings to create a board style that is comfortable for study,
  screenshots, or long review sessions.
